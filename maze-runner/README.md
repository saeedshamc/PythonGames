# Maze Runner

یک بازی هزارتو (Maze) دو بعدی ساخته‌شده با Python و Pygame، با ساختار ماژولار. بازیکن باید در محدودیت زمانی از هزارتو عبور کند و به نقطه خروج برسد. هیچ دشمنی توی بازی نیست؛ چالش فقط از افزایش تدریجی اندازه و پیچیدگی هزارتو در هر مرحله میاد.

## ویژگی‌ها

- تولید خودکار و تصادفی هزارتو با الگوریتم Recursive Backtracker (DFS)
- تضمین حل‌پذیری هر هزارتو با اعتبارسنجی مسیر (BFS)
- ۱۰ مرحله که هر کدوم از قبلی بزرگ‌تر و پیچیده‌تره
- شمارش حرکات و تایمر مرحله
- افکت صوتی تولیدشده در کد (بدون نیاز به فایل صوتی خارجی)
- انیمیشن ساده برای بازیکن و نقطه هدف
- کدنویسی ماژولار: هر بخش در فایل جدای خودش

## پیش‌نیازها

- Python 3.9 تا 3.13 (پیشنهاد می‌شود؛ نسخه‌های خیلی جدید مثل 3.14 ممکنه هنوز پکیج آماده نداشته باشن)
- pygame-ce
- numpy (اختیاری، فقط برای صدا)

## نصب و اجرا

```bash
pip install -r requirements.txt
python run.py
```

اگر `numpy` نصب نباشد، بازی بدون صدا اما کاملاً قابل بازی اجرا می‌شود.

### ⚠️ اگر نصب pygame روی ویندوز خطا داد

اگه پیام خطای build کردن pygame از سورس رو دیدی (چیزی شبیه `ModuleNotFoundError: No module named 'distutils.msvccompiler'`)، دلیلش معمولاً اینه که نسخه پایتونت خیلی جدیده (مثلاً 3.14) و برای pygame معمولی هنوز wheel آماده منتشر نشده، پس pip می‌خواد از سورس بسازتش که روی ویندوز نیاز به Visual Studio Build Tools داره.

این پروژه دیگه به‌جای `pygame` از `pygame-ce` (نسخه Community Edition) استفاده می‌کنه که wheel آماده برای نسخه‌های جدیدتر پایتون هم داره و همون‌طوری با `import pygame` کار می‌کنه، پس مشکل حل می‌شه:

```bash
pip install -r requirements.txt
```

اگه بازم خطا گرفتی، ساده‌ترین راه اینه که یک نسخه پایتون پایدارتر مثل 3.11 یا 3.12 رو از [python.org](https://www.python.org/downloads/) نصب کنی و پروژه رو با اون اجرا کنی.

### ⚠️ اجرای فایل درست

فایل اصلی برای اجرا `run.py` هست، نه `main.py`. مطمئن شو داخل پوشه‌ی درستی هستی (پوشه‌ای که `run.py` و `requirements.txt` توش هست) قبل از اجرای دستور:

```bash
cd maze-runner
python run.py
```

اگه بعد از اکسترکت کردن زیپ یک پوشه تودرتو مثل `maze-runner (1)\maze-runner\maze-runner` دیدی، باید وارد داخلی‌ترین پوشه‌ای بشی که واقعاً فایل `run.py` توشه.

### اجرا به‌صورت پکیج نصب‌شده (اختیاری)

```bash
pip install -e .
maze-runner
```

## کنترل‌ها

| کلید | عملکرد |
|---|---|
| فلش‌های جهت‌دار / W A S D | حرکت |

```
maze-runner/

├── requirements.txt
├── src/
│   └── maze_runner/
│       ├── __init__.py
│       ├── main.py            # نقطه ورود پکیج
│       ├── game.py            # کلاس Game، حلقه اصلی و رندر
│       ├── maze.py            # تولید هزارتو و مسیریابی BFS
│       ├── audio.py           # مدیریت افکت‌های صوتی
│       ├── config.py          # ثابت‌ها، رنگ‌ها، وضعیت‌های بازی
│       └── levels.py          # تعریف مرحله ثابت و پیکربندی مراحل

└── README.md
```

## توسعه بیشتر

اندازه هزارتو و محدودیت زمانی هر مرحله در `src/maze_runner/levels.py` داخل `LEVEL_CONFIGS` قابل تغییره. هر مقدار یک تاپل `(width, height, time_limit_seconds)` هست؛ برای اضافه کردن مرحله جدید فقط یک تاپل دیگه به لیست اضافه کن.
