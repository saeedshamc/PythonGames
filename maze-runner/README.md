# Maze Runner

یک بازی هزارتو (Maze) دو بعدی ساخته‌شده با Python و Pygame، با ساختار ماژولار. بازیکن باید از یک هزارتوی تصادفی عبور کند، به نقطه خروج برسد و از هیولاهایی که با الگوریتم جست‌وجوی BFS تعقیبش می‌کنند فرار کند.

## ویژگی‌ها

- تولید خودکار و تصادفی هزارتو با الگوریتم Recursive Backtracker (DFS)
- تضمین حل‌پذیری هر هزارتو با اعتبارسنجی مسیر (BFS)
- ۶ مرحله با سختی افزایشی (اندازه بزرگ‌تر، دشمن بیشتر، زمان محدودتر)
- دشمنانی با هوش مصنوعی ساده که کوتاه‌ترین مسیر به بازیکن را دنبال می‌کنند
- شمارش حرکات و تایمر مرحله
- افکت صوتی تولیدشده در کد (بدون نیاز به فایل صوتی خارجی)
- انیمیشن ساده برای بازیکن، دشمنان و نقطه هدف
- کدنویسی ماژولار: هر بخش (تنظیمات، مراحل، تولید هزارتو، صدا، موجودیت‌ها، حلقه بازی) در فایل جدای خودش

## پیش‌نیازها

- Python 3.8+
- pygame
- numpy (اختیاری، فقط برای صدا)

## نصب و اجرا

```bash
pip install -r requirements.txt
python run.py
```

اگر `numpy` نصب نباشد، بازی بدون صدا اما کاملاً قابل بازی اجرا می‌شود.

### اجرا به‌صورت پکیج نصب‌شده (اختیاری)

```bash
pip install -e .
maze-runner
```

## کنترل‌ها

| کلید | عملکرد |
|---|---|
| فلش‌های جهت‌دار / W A S D | حرکت |
| Enter | شروع بازی / رفتن به مرحله بعد |
| R | تکرار مرحله فعلی |
| Esc | خروج |

## ساختار پروژه

```
maze-runner/
├── run.py                       # نقطه ورود ساده برای اجرای مستقیم
├── pyproject.toml               # تنظیمات پکیج قابل نصب
├── requirements.txt
├── src/
│   └── maze_runner/
│       ├── __init__.py
│       ├── main.py              # نقطه ورود پکیج
│       ├── game.py              # کلاس Game، حلقه اصلی و رندر
│       ├── entities.py          # کلاس Enemy
│       ├── maze.py              # تولید هزارتو و مسیریابی BFS
│       ├── audio.py             # مدیریت افکت‌های صوتی
│       ├── config.py            # ثابت‌ها، رنگ‌ها، وضعیت‌های بازی
│       └── levels.py            # تعریف مرحله ثابت و پیکربندی مراحل
├── LICENSE
└── README.md
```

## توسعه بیشتر

تنظیمات هر مرحله (اندازه هزارتو، تعداد دشمن، محدودیت زمانی، سرعت دشمن) در `src/maze_runner/levels.py` داخل `LEVEL_CONFIGS` قابل تغییر است. رنگ‌ها و ثابت‌های ظاهری در `src/maze_runner/config.py` هستند.
